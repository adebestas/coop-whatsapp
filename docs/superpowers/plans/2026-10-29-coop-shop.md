# Coop Shop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship interest-free asset financing for bulk-purchased cooperative goods: admin catalog, PIN-confirmed member orders, admin approval/dispatch, and installment collection from savings with payroll fallback.

**Architecture:** Two new Prisma models (`ShopItem`, `ShopOrder`) plus `Loan.kind`, one service (`src/services/shop.ts`) for catalog/order/dispatch/collection logic, one command router (`src/services/shop-commands.ts`) for raw-text parsing and role checks, wiring in `conversation.ts` and `scheduler.ts`, and `tests/shop.test.ts`.

**Tech Stack:** TypeScript, Prisma (SQLite dev / PostgreSQL prod), Vitest, existing messaging/PIN/session helpers.

**Spec:** `docs/superpowers/specs/2026-10-29-coop-shop-design.md`

## Global Constraints

- Kobo integers only (₦1 = 100 kobo); `parseNaira` for user input, `formatBalance` for output.
- No comments in production code unless they explain non-obvious intent.
- Both `prisma/schema.prisma` and `prisma/schema.local.prisma` must stay in sync.
- `npx tsc --noEmit`, `npm run lint` (src only), `npm run format:check` (src only) must pass.
- Admin actions allowed for `role === "admin" || role === "superadmin"`, scoped to the actor's `cooperativeId`.
- Shop financing is interest-free: `interestRate = 0`, `adminCharge = 0`.
- Repo rule: no git commit or push unless the user explicitly asks.

```ts
export function installmentSchedule(priceKobo: number, months: number) {
  const monthly = Math.floor(priceKobo / months);
  return { monthly, last: priceKobo - monthly * (months - 1) };
}

export async function shopEligibility(memberId: string, priceKobo: number) {
  const member = await prisma.member.findUnique({
    where: { id: memberId },
    select: {
      status: true, frozenAt: true, supervisoryFrozenAt: true,
      wallet: { select: { totalSaved: true } },
      shopOrders: { where: { status: { in: ["pending", "approved"] } }, select: { id: true } },
    },
  });
  if (!member) return { ok: false, message: "You need to join a cooperative first." };
  if (member.status !== "active") return { ok: false, message: "Your account is not active." };
  if (member.frozenAt || member.supervisoryFrozenAt) return { ok: false, message: "Your account is frozen." };
  if (member.shopOrders.length > 0) return { ok: false, message: "You already have a shop order in progress." };
  const arrears = await prisma.loan.aggregate({
    where: { memberId, kind: "shop", status: "partial" },
    _sum: { balance: true },
  });
  if ((arrears._sum.balance ?? 0) > 0) return { ok: false, message: "Clear your shop arrears before ordering again." };
  const outstanding = await prisma.loan.aggregate({
    where: { memberId, kind: "shop", status: { in: ["disbursed", "partial"] } },
    _sum: { balance: true },
  });
  const cap = Math.floor((member.wallet?.totalSaved ?? 0) / 2);
  if (priceKobo + (outstanding._sum.balance ?? 0) > cap) {
    return { ok: false, message: `That is above your shop limit of ${formatBalance(cap)} (50% of your savings).` };
  }
  return { ok: true, message: "ok" };
}
```

`createShopOrder` re-runs eligibility inside a transaction, loads the item scoped by `cooperativeId`, validates `months` and stock, and inserts `status: "pending"` with a `SHOP-` ref.
`dispatchShopOrder` runs in `withTx`: re-check `approved` + stock, decrement stock, create the loan, link `loanId`, `recordLedger({ type: "balance_sheet", category: "assets:loan_portfolio", amount: price })` and, when `stockQty !== null`, the matching `assets:inventory` counter-entry; return the schedule text.
