# Agent instructions for coop-whatsapp

1. Read `RULES.md` and `CODEBASE_MAP.md` at the start of every session, before
   planning or editing anything.
2. Before a major change, re-read `CODEBASE_MAP.md`; update it in the same change
   whenever entry points, folders, storage or sensitive boundaries move.
3. A task is not finished until `npm run check` exits 0. Paste its output in the
   hand-off summary.
4. Commit only when explicitly asked. Never commit secrets or `.env` files.
